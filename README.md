## Инструкции по запуску проекта

Для корректной работы проекта необходимо запустить локальный сервер базы данных (`json-server`) и сервер фронтенда.

### Предварительные требования

Убедитесь, что на вашем компьютере установлен [Node.js](https://nodejs.org).

### Шаг 1. Установка зависимостей

Перед первым запуском установите все необходимые пакеты. Откройте терминал в корневой папке проекта и выполните команду:

```bash
npm install
```

### Шаг 2. Запуск локального API (json-server)

Проект использует `json-server` для имитации работы бэкенда и хранения данных (карточек товаров и конфигураций) в файле `db.json`.

Запустите сервер базы данных на порту `3000`:

```bash
npx json-server db.json --port 3001
```

*После успешного запуска API будет доступно по адресу: `http://localhost:3000`*

### Шаг 3. Запуск веб-сервера фронтенда

Запустите статический сервер напрямую из корня проекта:

 ```bash
> npx serve .
```
